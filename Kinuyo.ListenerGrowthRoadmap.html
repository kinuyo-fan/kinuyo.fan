いまの状況

強みは十分。足りないのは「新しい人の入口」

5年の積み重ねと歌の力で、ダイヤモンドクラスの上位に入れています。TOP3に届かない差は、外から入ってくる新しい人の数が足りない！。

強み

  • 5年の実績と、上位に入る安定感
  • 歌唱力と、9月の新曲「Dream Time」「Fly High」
  • 10月から東京・福岡・愛知・山口・大阪のツアー
  • HPにスケジュール、CD、ショップ、ファンクラブが揃っている

課題(公開情報からの仮説)

  • HPのトップに、TikTok LIVEへ誘う入口が見当たらない
  • 初めての人向けの入口と、常連の居場所が分かれていない
  • イベントの順位が、常連の応援に寄りやすい
考え方

カギは「入る → 残る → 戻る」の3つ

2026年のTikTok LIVEは、ギフトの金額よりも、長く見てもらえることとコメントのやり取りが大切にされる流れだと、複数の解説がサイトの情報あり。新規を増やす近道は、見ている時間とコメント率を上げること！新規のこの３つの動向を記録・分析・Acitonに繋げよう

STEP 1入る

初めての人に見つけてもらう

配信前の予告ショート動画、分かりやすい配信タイトル、決まった配信時間で入口を作る。

見る数字:配信開始10分の入室数

STEP 2残る

最初の5分で帰らせない

1曲目に乗れるを歌い、初見さんの名前を呼び、コメントで選べる企画を入れます。

見る数字:平均視聴時間 ・ コメント数÷視聴者数

STEP 3戻る

次も来たい理由を渡す

次回の日時と曲の予告、リクエスト受付、フォロー、ツアーやファンクラブの案内で、また会う約束をします。

見る数字:新規のうち2回目も来た人の割合

歌ライバーの強みは、1曲が終わるまで人が留まることです。曲の順番と、曲の合間のひと言が、そのまま数字になります。

90日計画 ・ 2026年11月〜2027年1月

4つのフェーズで進める

各フェーズの終わりに「次へ進む条件」を置きました。条件を満たしたら次に進みます。

PHASE 0

自枠の分析をする

11/3 〜 11/9
  1. 直近10配信の入室数、平均視聴時間、コメント数、新規フォロー数をメモする
  2. 常連の定位置(曜日・時間・曲)と、新規が最も入った配信の共通点を書き出す
  3. 同じ歌ジャンルで伸びている3人の、配信の最初の5分を観察する

次へ進む条件自分の基準値が、数字で言える。きちいけど分析しよう！

PHASE 1

入口と型を整える

11/10 〜 12/7
  1. 配信時間を固定し、HPとSNSに同じ表記で載せる
  2. 1配信の型を決めて、4週間同じ型で回す
  3. 配信の30〜60分前に、その日のメイン曲で15〜30秒のショート動画を出す
  4. HPのトップに「TikTok LIVEはこちら・次回の日時・初めての方へ」の枠を足す

次へ進む条件最初の5分の離脱が減り、コメント率が上がっている。

PHASE 2

外から人を呼ぶ

12/8 〜 1/4
  1. ショート動画を週4本。「サビ映え」「リクエスト企画」「ツアーの舞台裏」の3種で回す
  2. 同じジャンルの歌ライバーとのコラボ配信を月2回行い、相手のリスナーに会う
  3. 常連に「初見さんへのひと声」をお願いして、歓迎の空気を見せる
  4. ツアー会場とファンクラブへの案内を、配信の終盤に決まった台本で入れる

次へ進む条件新規フォローが基準値の1.5倍以上で、2回目の来場率も測れている。

PHASE 3

イベントで試して仕組みにする

1/5 〜 2/1
  1. 年始のイベントを「新規獲得の実験場」と位置づけ、バトルは相手を選ぶ
  2. 良かった施策だけを残し、効かなかったものは止める
  3. 数字と学びを1枚にまとめて、次の90日の計画に使う

ゴール「何をすると新規が増えるか」を3つ言える。

配信の型

最初の5分で、残るかどうかが決まる

TikTok LIVEは、スクロール中に偶然見つけた人が、数十秒で残るかを決める場です。開始から5〜10分の反応が、その後の見られ方を左右するという解説があります。そこで1配信を3つに分けます。

5分
中盤
終盤
0分5分40分 → 終了
0 〜 5分

盛り上がる曲から入る

あいさつより先に歌います。タイトルに「今日の1曲目」と書いておくと、来た人が何の配信か一目で分かります。

5 〜 40分

みんなで参加する中盤

「次はAとBどっち?」のように、1回のコメントで参加できる選択式にします。初見さんの名前を呼び、曲の合間に必ず1回、話しかけます。

40分 〜 終了

また来る理由を渡す

次回の日時と曲を予告します。リクエスト、フォロー、ツアー、ファンクラブを30秒の決まった台本で案内します。

歌ライバーならではの工夫

  • 曲の前に「この曲は〇〇な人に」と添えて、初見の人が自分のことだと思えるようにする
  • 定番曲と、季節やトレンドの曲を3:1で混ぜて、検索から来る人も拾う
  • 配信タイトルは「歌」「リクエスト」「ジャンル」など、内容が一目で分かる言葉にする
  • 常連が新規に優しくしてくれた場面を、感謝として名前を出して伝える
TikTokの外

HPとSNSを「入口」に変える

公式HPには、スケジュール、プロフィール、CD、ショップ、ファンクラブ、出演依頼、ライブ予約、クラファンまで揃っています。足りないのは、TikTok LIVEの視聴者を迎える専用の入口です。

  • 高
    HPトップに新しい枠を作る「TikTok LIVE 次回〇/〇 20:00」と「初めての方へ(3行)」を一番上に置く。
  • 高
    スケジュールをひとつにまとめるライブ(ツアー)の日程に、TikTok LIVEの配信枠も同じ表に載せる。
  • 中
    初見さん用ページを作る代表曲3曲、配信の楽しみ方、コメントの仕方を1ページにまとめて、プロフィールのリンクに設定する。
  • 中
    ツアーと配信を往復させる会場では「TikTokで会えます」、配信では「会場で会えます」を同じ台本で案内する。
  • 中
    新曲を使い回す「Dream Time」「Fly High」のサビを、ショート動画と配信の盛り上がる曲の両方に使う。

新しく来た人にとっては、次に会える場所と時間が分かることが、最初のフォローの理由になります。

イベント戦略

TOP3の壁は「新規の流入量」で越える

上位との差を常連の応援だけで埋めると、消耗します。イベントを「順位を追う場」と「新規を迎える場」に分けて、期間中に入口を広げます。

  1. 開始前の1週間イベントの告知ショート動画を毎日1本。ファンの応援を前倒しで集める。
  2. 初日と中盤バトルは、自分より少し大きい相手のピーク時間を選ぶ。相手のリスナーに見てもらえる。同じ規模の歌ライバーを優先する。
  3. ラスト48時間常連の熱量を使うのはここだけ。新規には応援の仕方を1枚で見せて、無理のない参加をすすめる。
  4. 終了後72時間イベント中に来た新規へお礼を伝え、ショート動画でもう一度来てもらう。

新規が増えれば、上位との差も縮まります。順位とあわせて「イベント期間中の新規フォロー数」も成果として記録しましょう。

数字で見る

追う数字は5つだけ

目標の数字は、PHASE 0で取った基準値をもとに決めます。

配信開始10分の入室数基準値の1.3倍入口の強さ
平均視聴時間基準値の1.2倍残る力
コメント数 ÷ 視聴者数基準値より上げるやり取りの質
週の新規フォロー数基準値の1.5倍新規の獲得
新規の2回目の来場率まず測る戻る力
